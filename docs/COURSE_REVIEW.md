# 课程审查与修订记录

日期：2026-09-15。范围：19 章、12 个专题、目录、点评说明、互动实验与共用图片组件。

本轮使用 Astra 完成正文修订，并对新增组件做第二轮只读复核；主代理负责组件实现、整合和浏览器验证。没有生成新的光学、参数或设备界面图。

## 已处理的问题

| 审查发现 | 修订结果 |

| 原地变焦错误改变前后比例 | 平面实验按针孔投影计算；分开原地变焦与后退同构图，提供数值读数 |

| 手机三联图和说明太小 | 窄屏逐幅滑动，实测单幅约 306px、说明约 14px；提供放大 |
| 公共站点不知道如何交作业 | 明确静态站没有上传/自动回复；提供自评、重拍、复比与可复制点评提示 |
| 第 17 章前置后仍依赖未学内容 | 改为高级导读：先选方向和试拍，学完后再回来做挑战 |
| 浅色导航变量使用渐变导致透明 | 使用有效颜色值，消除顶栏与正文重叠；补充新模块深色主题样式 |

## 验证

- `npm test`：6 项关系与回归测试通过，覆盖固定站位比例、同构图后退、光线方向、非默认视角锁定、曝光档数、ISO/快门配平。
- `npm run build`：36 页静态输出通过；另用 GitHub Actions 环境变量和标准 `dist` 目录验证项目子路径。
- 浏览器检查手机 `390 × 844`、平板 `834 × 1194`、深浅主题；34 个侧栏页面无全页横向溢出，每页一个自动标题。
- 验证滑块、预设、锁定、ISO 条件切换、后期五步骤与撤回、大图实际尺寸、Escape 退出及焦点恢复。
- 后期步骤使用同一个图像地址；真实样张原始比例与显示比例一致（允许像素舍入）。
- `git diff --check` 通过。浏览器没有捕获到运行时错误或警告；构建仍提示按需加载的 Three.js 分块超过 500 kB。
