# AI Teaching Image Assets

`src/assets/lessons/` 中的 JPEG 是由 Codex 内置图像生成工具创建的教学模拟资产。源 PNG 不提交到仓库，项目内 JPEG 以质量 `88` 转换，构建时再由 Astro 输出 WebP。

所有页面必须通过 `GeneratedLessonVisual` 或等效显式文字说明它们是 AI 教学模拟图。

## 通用约束

- 同组内尽量保持主体、机位、焦段、背景和时机一致，只改变被教学的变量。
- 不生成文字、参数、UI、品牌、日期边框或水印。
- 不声称是小米 15 Ultra 实拍、真实胶片测试或厂商配方复刻。
- 不用生成图证明焦距、透视、动态范围、ISO 噪声和白平衡的精确数值。
- 涉及人物时只使用成年人，不以脆弱处境制造视觉冲击。
