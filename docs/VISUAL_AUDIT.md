# Visual Audit

这份文档记录教程视觉素材的审计结果，避免后续为了“图多”而牺牲技术准确性。

## 判断原则

- 精确关系用代码示意：焦距、透视、景深、曝光变量、直方图、手机 UI 和 Three.js 空间实验不能由生成图替代。
- 复杂现场用照片：姿态、背景、时机、取景、食物布置、风格和组图角色适合用真实样张或 AI 教学模拟图补充。
- AI 图必须标注：每张生成图都通过 `GeneratedLessonVisual` 显示“教学模拟”说明，不冒充实机、胶片或参数测试。
- 真实样张优先：已有开放许可实拍样张时不重复生成相似内容；第三方实拍继续维护 `IMAGE_CREDITS.md`。
- 最终目标是替换：遇到合适的用户授权作品或小米 15 Ultra 同场景实拍，应优先替换相应模拟图。

## 仍缺少的真实素材

以下内容无法由生成图可靠补齐，是下一阶段更高价值的素材：

1. 小米 15 Ultra 当前 HyperOS 相机界面截图：点按对焦、曝光补偿、锁定、连拍、专业模式。
2. 同一机位的 `0.6x / 1x / 2x / 3x / 4.3x` 实拍，保留 EXIF 和站位记录。
3. 同场景快门、ISO、WB、曝光补偿对照，保留原文件和参数。
4. RAW/DNG 与普通成片的高光、暗部和颜色对照。
5. 用户授权的“初拍 → 点评 → 重拍”作业案例。

生成图不能填补这些证据型缺口。
