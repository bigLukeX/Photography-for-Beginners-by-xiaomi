这一章不是让你从头到尾背完。

它更像一个出门前、拍摄中、复盘时都能查的工具箱：你想拍清楚、拖影、颗粒、梦境感、post-punk、shoegaze，都可以先回来看对应的参数起点。

如果你要查的是直方图、峰值对焦、RAW/DNG、稳定或文件输出，去 [专业模式进阶工具](../../guides/pro-mode-tools/)；本章继续专注“参数怎样改变画面”。

## 这一章学完以后，你应该能做到

- 看到一个场景时，知道快门、ISO、白平衡大概从哪里开始
- 知道自动模式、曝光补偿、专业模式分别适合什么时候用
- 用参数控制拖影、失焦和亮暗取舍，区分噪点与后期颗粒
- 把高级风格变成可执行的拍摄配方
- 以后换相机时，能把这些逻辑迁移过去

## 先记住一句话

**参数不是答案，是起点。**

同样的 `1/15s`，拍走路的人、车灯、雨夜玻璃、室内灯，都可能完全不一样。

所以你要学的不是“某个数字一定对”，而是：

- 这个数字大概会带来什么结果
- 如果结果不对，下一步往哪里调
- 这个代价你能不能接受

## 一张总表：先从这里查

**先分清模式：**普通自动只调 EV，快门和 ISO 由手机选；部分自动（当前版本如支持）固定一项，让另一项自动，并检查 EV 是否生效；全手动固定快门、ISO 和镜头后，用快门、ISO 或现场光改变曝光，不再叠加独立 EV。下表及风格配方里的快门/ISO 是手动试拍范围，EV 是自动模式的另一条路径，不要求三项同时设定。

快门能否定住动作还取决于主体速度、方向、距离和使用的镜头。数值只作起点，拍完放大检查；防抖能减轻手抖，不能冻结人物移动。

先以 **1x 主摄、f/1.63 固定光圈**练习，见 [小米官方光圈说明](https://www.mi.com/global/support/faq/details/KA-541898/)。其他实体镜头光圈不同；切镜头后重新测光。最低 ISO、最快快门和可用模式以当前版本为准。

强光下最低 ISO 配最快快门仍过曝时，先换阴影或较暗时段；已有合适 ND 减光镜时可用。回到自动模式可以让手机重新安排曝光，但 HDR 不是挽救过曝的保证。阴天、深阴影和室内靠窗也不能视为同一种亮度。

换成相机时，光圈是曝光数字的另一部分。同场景、同快门下，从 `f/1.63` 收到 `f/4` 或 `f/5.6`，等亮 ISO 分别约需提高 `2.6` 或 `3.6` 档；也可以放慢快门，代价是运动更容易糊。下面的风格配方同样要按现场光和实际调用的镜头修正。

## 快门：控制时间，不只是控制清晰

快门越快，越像切下一瞬间。

快门越慢，越像把一段时间压进照片。

| 快门 | 画面效果 | 练习方向 |
| --- | --- | --- |
| `1/1000s` | 定住快速动作 | 白天车、人、运动 |
| `1/250s` | 日常抓拍稳 | 街拍、朋友、行走 |
| `1/125s` | 人像基本安全 | 站定人物、半身人像 |
| `1/60s` | 手持边界 | 静物、弱光、轻微风险 |
| `1/15s` | 人物开始拖 | 模糊记忆、夜路、经过的人 |
| `1/4s` | 明显拖影 | 车灯、人群、shoegaze 气质 |
| `1s+` | 时间流动 | 车流、水面、固定机位 |

如果你想拍清楚：往更快快门走。

如果你想拍拖影：往更慢快门走。

如果画面太暗：提高 ISO、找更亮现场光、或者接受更慢快门。

## ISO：控制信号增益，不能指定颗粒气质

固定镜头、现场光和快门时，提高 ISO 通常让输出更亮，但没有增加传感器收到的光。噪点还取决于入光量、传感器和降噪算法；它与后期颗粒不是同一种控制。以下是常见使用情境，不是每档 ISO 必然出现的画质。

| ISO | 画面倾向 | 适合 |
| --- | --- | --- |
| `50/100` | 干净、细节好 | 白天、慢门固定、干净风景 |
| `200/400` | 提高输出亮度 | 室内、阴天，回放检查纹理 |
| `800` | 可为较快快门提供亮度余量 | 夜景抓拍，检查噪点和高光 |
| `1600+` | 暗光下可能有明显噪点或涂抹 | 动作优先时接受代价，不为风格刻意追高 |

暗光照片可以保留噪点，但不要为了粗粝而刻意严重欠曝。想控制颗粒大小和强度，用后期副本更可重复；保留原始文件，检查颗粒是否遮住关键轮廓。

## 曝光补偿：自动模式里最重要的控制

很多时候你不需要进专业模式，只需要曝光补偿。

| 曝光补偿 | 适合什么 | 风险 |
| --- | --- | --- |
| `-1EV` | 强灯牌、夜景、高反差 | 暗部可能死黑 |
| `-0.7EV` | 夜景保高光 | 人脸可能偏暗 |
| `-0.3EV` | 日常稍微压住亮部 | 整体略暗 |
| `0EV` | 自动判断可接受 | 手机可能把夜景提太亮 |
| `+0.3EV` | 柔光、人脸、阴天 | 高光风险增加 |
| `+1EV` | 漂浮、过曝边缘、梦境感 | 细节容易丢 |

你要养成一个习惯：夜景和高反差场景，先试 `-0.3EV` 或 `-0.7EV`。

## 白平衡：不是只追求准确

白平衡决定照片像什么温度的记忆。

先注意一个常见陷阱：**光源色温和相机 WB 设定造成的画面偏色，不是同一个方向。**

- 低 Kelvin 光源通常偏暖，高 Kelvin 光源通常偏冷。
- 但在同一个场景里降低相机 WB 数值，画面通常会变冷；提高 WB 数值，画面通常会变暖。

| 专业模式 WB 设定 | 同一场景中的画面倾向 | 可以对应的用途 |
| --- | --- | --- |
| `2800K-3500K` | 相对更冷、更蓝 | 抵消暖黄灯，或制造冷感城市气氛 |
| `4000K-5000K` | 中性到略冷 | 混合光、阴天、日常观察 |
| `5200K-6000K` | 中性到略暖 | 日光附近起步，观察白色和肤色 |
| `6500K+` | 相对更暖、更黄红 | 暖色记忆、夕阳感、室内亲密感 |

如果你拍的是作业和基础练习，先保持相对准确。

如果你拍的是高级篇，可以让白平衡偏离现实，但偏离要统一。

不知道当前场景该从多少开始时，先看自动白平衡给出的结果，再分别向低值和高值各试一档。不要脱离现场把某个 Kelvin 数字当成固定滤镜。

## 对焦、失焦和测光

对焦控制清楚，测光控制亮暗参考。

你可以这样理解：

- 想拍清楚：点主体对焦
- 想保脸：点脸部测光
- 想保灯牌：点灯牌附近测光，必要时压暗
- 想拍失焦：对与主体距离明显不同的参照物锁焦，或用 `MF`（当前版本如提供）微调离焦；先留一张对主体合焦的对照。旁边同距离的物体通常无效
- 想等人进画面：先对焦锁定在某个距离，再等人走进来

失焦类照片要保留一个锚点：

- 轮廓
- 姿态
- 光源
- 影子
- 背景结构

否则它不像表达，只像失误。

## 风格配方

这些名称只是本课程的观察练习方向，不是摄影师、胶片或音乐流派的标准参数。先完成可读的中性版本，再试一种偏移；轮廓消失、肤色无法接受或灯光连成白片时，就退回上一档。不同路线无需都追求高 ISO。

### post-punk 城市夜晚

- 场景：地铁口、楼道、停车场、便利店门口
- 焦段：`1x` 或轻长焦
- 快门：`1/60s-1/250s`
- ISO：`400-1600`
- 曝光：`-0.3EV/-0.7EV`
- 后期：低饱和、高反差、允许颗粒

### midwest emo 日常空场

- 场景：房间、窗边、公交站、空椅子、傍晚路口
- 焦段：`1x`
- 快门：`1/125s-1/250s`
- ISO：`50-400`
- 曝光：`0EV` 或略暗
- 后期：低饱和、低对比一点、保留普通细节

### dreampop 柔光漂浮

- 场景：窗帘、玻璃、雨天、逆光、橱窗
- 焦段：长焦或人像模式谨慎使用
- 快门：`1/60s-1/250s`
- ISO：`100-800`
- 曝光：`+0.3EV` 或允许局部高光溢出
- 后期：降低清晰度、降低纹理、统一偏冷或偏粉

### shoegaze 噪声和吞没

- 场景：演出、人群、车灯、强光源、夜晚玻璃
- 焦段：`1x` 或超广角贴近
- 快门：`1/15s-1/4s`
- ISO：`400-1600`
- 曝光：允许高光溢出，但保留暗部骨架
- 后期：颗粒、低饱和、失焦、拖影可以叠加

### 森山大道式粗粝压力

- 场景：街头近距离、强光阴影、黑白也可以
- 焦段：`1x`
- 快门：`1/125s-1/500s`
- ISO：`800+` 可以接受
- 曝光：压暗，保留硬光和黑
- 后期：高反差、粗颗粒、少一点“漂亮”

### Stephen Shore 式日常观看

- 场景：普通街角、路边、室内、餐桌、停车场
- 焦段：`1x` 或轻长焦
- 快门：`1/125s-1/250s`
- ISO：`50-400`
- 曝光：相对准确
- 后期：颜色克制，空间关系清楚，不靠夸张效果

### 日式胶片三路线速查

- 清透日常：`1x/2x`，人物 `1/125s-1/250s`，`ISO 50-400`，`0EV` 起步，高光安全时才试 `+0.3EV`；后期柔化对比、压高光、轻颗粒。
- 昭和暖旧：`1x`，`1/60s-1/125s`，`ISO 100-1000`，`-0.3EV～0EV`；保暖灯，后期做琥珀高光、轻微青绿阴影和中等颗粒。
- 雨夜青绿：`1x/2x`，定住人物 `1/60s-1/125s`，拖影 `1/15s-1/8s`，`ISO 400-1600`，`-0.3EV/-0.7EV`；只在灯周围保留有限光晕。

完整的场景判断、后期滑块范围和作业见 [高级专题：日式胶片风格](../../guides/japanese-film-style/)。

### 布列松式彩色决定性瞬间

- 场景：路口、楼梯、门框、斑马线、公交站、光影边界
- 焦段：`1x` 或 `2x`
- 快门：`1/250s-1/1000s`
- ISO：白天 `50-400`，阴天或室内 `400-800`
- 曝光：相对稳定，优先让动作和结构可读
- 拍法：先找几何结构，再等人物姿态进入正确位置
- 后期：颜色可以保留，但不要让调色抢走瞬间和秩序

## 手机和相机的差异

手机上要特别记住：

- 手机会自动 HDR、多帧合成、降噪和锐化
- 同样的 ISO 和快门，不一定和相机质感完全一样
- 手机光圈多数不可控，所以你更依赖焦段、距离、对焦、快门、ISO 和后期
- 手机夜景模式可能会“修得太干净”，高级篇有时反而适合普通模式或专业模式

换成可换镜头相机时，通常会有更多选择：

- 可控光圈
- 通过光圈、实际焦距与距离控制光学景深；手机也有真实光学景深，人像算法是额外模拟
- 更大的传感器通常带来单帧动态范围与暗光优势，但不能只按设备类别断言每张结果
- 更精确的手动对焦和慢门控制

如果使用外接闪光灯，还要检查机身与当前快门模式的闪光同步速度；普通同步常见约 `1/200s–1/250s`，并非由画幅单独决定。高速同步需机身和闪灯共同支持，不能直接照搬白天的快速快门；以说明书为准，可参考 [尼康闪光同步说明](https://onlinemanual.nikonimglib.com/z7_z6/en-nsg/09_menu_guide_05_e01.html)。

但底层判断不变：你还是在决定光、时间、清晰度、颜色和代价。

## 可重复的参数实验：等亮不等于同样入光

找一件有纹理的静物，旁边放一张白纸，在不闪烁、亮度稳定的室内光下固定手机。保持同一镜头、构图、对焦、白平衡、照片格式和处理风格；如有可关闭的 HDR 或夜景合成，关闭并记录。先试 `1/15s + ISO 100`，再试 `1/60s + ISO 400`，最后 `1/240s + ISO 1600`（没有该档就用 `1/250s`，亮度会略有差异）。

这三组输出亮度应当接近，但后两组的入光时间减少，ISO 同时提高。放大相同区域比较纹理、暗部彩噪和降噪涂抹。这是在观察“更短快门加更高 ISO”的共同代价，**不是只改变 ISO 的因果实验**。若起始照片太亮或太暗，统一调整三组快门并保持四倍关系；超出可调范围时换现场光。保留照片参数记录，别在不同镜头或不同夜景算法之间比 ISO。

另做一组只改 ISO 的实验时，固定快门、光线和镜头，拍低、中、高三档，预期亮度一起改变。它能说明增益，不适合直接据此排名等亮画质。当前版本不提供手动控制时，先完成自动 EV 对照，并说明不能控制的变量。

慢门若在白天过曝：先用最低可用 ISO，再换到阴影或黄昏；仍过曝就缩短快门。已有合适减光镜时可用。全手动固定快门与 ISO 后，负 EV 不能替代减光。

## 交作业前自检

- 对照组是否明确哪些参数固定、哪些自动、哪些手动改变？
- 有没有把更亮误当更干净，或把不同处理算法误当 ISO 差异？
- 参数说明能否从原文件或拍摄记录核对？不能确认时就写未知，不从模拟图反推数值。

## 我会怎么点评这一章

我会重点看：

1. 你是否能说清每个参数改变了什么
2. 你的参数选择是否服务拍摄目标
3. 你是否能接受并描述参数代价
4. 风格配方是否真的落到拍摄动作
5. 你是否开始从“碰运气”变成“可复现”
