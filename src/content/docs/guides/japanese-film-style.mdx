“日式胶片风格”不是一卷叫作“日式”的胶片，也不是所有日本摄影都长一个样。

网络上这个词通常把几种不同视觉倾向放在一起：

- 柔和、明亮、颜色克制的日常负片感
- 暖色高光、青绿色阴影和家庭相册般的怀旧感
- 雨夜、便利店、街灯与颗粒组成的城市负片感

这三种方向可以互相借用，但不能简单理解成“加绿色、降饱和、铺一层颗粒”。这一专题要练的是：**先在现场找到适合的光和颜色，再用后期完成风格。**

## 学完以后，你应该能做到

- 分清三种常见的日式胶片方向，而不是只会套同一个滤镜
- 用小米 15 Ultra 在拍摄时保住适合后期的高光、肤色和阴影
- 理解色温、色调、曲线、HSL、颗粒和光晕分别解决什么问题
- 做出有胶片气质、但不过度发黄、发绿或褪色的照片
- 把其中一种方向拍成统一的 6-12 张小系列

先观察它们不变的部分：机位、焦段、建筑、人物位置和构图。真正变化的是：

- 光线时间
- 整体曝光
- 高光和阴影的软硬
- 阴影偏什么颜色、高光偏什么颜色
- 颗粒与灯光晕染的强弱

所以风格不是“颜色预设”，而是多项选择共同形成的结果。

## 胶片感的 4 层结构

### 1. 场景和光线

适合的现场会让后期轻松很多：

- 清透日常：阴天、窗边、树荫、浅色墙面、光线均匀的街道
- 昭和暖旧：傍晚、暖灯室内、旧店面、木头、红棕色物件
- 雨夜青绿：便利店、公交站、湿路面、冷暖混合灯、玻璃反射

### 2. 亮暗曲线

胶片风格不是一律低反差：

- 清透日常的高光过渡要柔，阴影可以轻轻抬起
- 昭和暖旧可以有中等反差，但黑位不要完全堵死
- 雨夜青绿可以更深、更硬，但灯外仍要保留一点环境层次

### 3. 颜色分离

只调白平衡，会让整张图一起变暖或变冷。更像胶片的颜色常常来自分区：

- 高光偏暖，阴影仍保留蓝绿
- 红色和棕色有存在感，但大面积绿色不过度荧光
- 肤色相对自然，背景可以有偏色

如果编辑器提供“色彩分级 / 阴影高光颜色 / HSL”，再做这种分离；没有就保持简单，不要靠全局色调硬染。

后面的滑块名称是功能方向，不是软件清单。当前手机编辑器没有 HSL、色彩分级、颗粒或光晕时，直接跳过那一项，不要为了凑齐配方破坏已经成立的照片。

### 4. 质感

颗粒、柔化和光晕是最后一层，不是第一层：

- 颗粒要和图片尺寸相称，缩小后仍不应像一层脏点
- 清晰度和纹理只略降，不要把所有边缘抹掉
- 光晕只围绕强灯、逆光边缘和反射出现，不该全图发雾

## 路线一：清透日常负片

这一类不是“惨白小清新”。它的重点是：**柔和、明亮、颜色有空气，但白色和肤色仍然有细节。**

适合拍：

- 阴天街道、车站、住宅区
- 窗边人物、白墙、浅色衣服
- 夏天树荫、蓝绿植物、饮料和日常小物
- 安静的旅行记录和朋友相处

<ParamCard title="清透日常拍摄起点" intro="先保护白色与脸，再让中间调轻一点。">
  <ul>
    <li>焦段：优先 `1x` 或 `2x`；人像避免用超广角贴脸。</li>
    <li>快门：人物 `1/125s-1/250s`，静物可降到 `1/60s`。</li>
    <li>ISO：白天 `50-200`，室内或阴天 `200-800`。</li>
    <li>曝光：`0EV` 起步；脸和白墙仍有细节时再试 `+0.3EV`，不要固定过曝。</li>
    <li>白平衡：先用自动；同一现场想更暖时再提高 WB 数值一小档，想更清冷则降低一小档。</li>
    <li>模式：普通模式足够；光比太大时保留普通成片，再补一张 RAW/DNG（如果当前版本提供）。</li>
  </ul>
</ParamCard>

后期起点，假设滑块中点为 `0`、范围约为 `-100～+100`：

| 调整 | 起步范围 | 目的与停止信号 |
| --- | --- | --- |
| 曝光 | `+5～+15` | 中间调更轻；白衣和天空失去纹理就停 |
| 对比 | `-10～-20` | 柔化亮暗；画面发灰、主体退掉就停 |
| 高光 | `-15～-35` | 找回窗户、皮肤和浅色墙细节 |
| 阴影 | `+5～+20` | 暗部透气；黑色变灰就停 |
| 饱和度 | `-5～-15` | 颜色克制；肤色没血色就停 |
| 清晰度 / 纹理 | `-5～-12` | 边缘柔一点；睫毛、文字全糊就停 |
| 颗粒 | `5～12` | 只提供触感，不抢画面 |

如果有 HSL：绿色可以稍降饱和、略向青移动；蓝色适度提亮。变化保持轻微，目标是空气感，不是薄荷绿滤镜。

## 路线二：昭和暖旧相册

这里的“昭和暖旧”是一种便于练习的网络风格描述，不代表整个昭和时代的照片都如此。它更接近：**暖色记忆、旧店面、家庭相册、琥珀高光与微微偏青绿的阴影。**

适合拍：

- 傍晚居民区、老店、站台和巷口
- 木头、红砖、旧招牌、棕红家具
- 暖灯下的家人、餐桌和小物
- 现在与过去同时存在的普通街景

<ParamCard title="昭和暖旧拍摄起点" intro="让现场本来就有暖色，不要后期把正午白光硬染成黄昏。">
  <ul>
    <li>焦段：`1x` 最像日常记录，`2x` 适合收店面和人物关系。</li>
    <li>快门：人物至少 `1/125s`；静态街景 `1/60s-1/125s`。</li>
    <li>ISO：白天 `100-400`，室内或傍晚 `400-1000`，允许自然噪点。</li>
    <li>曝光：`-0.3EV～0EV`；保住暖灯与窗户，不要把怀旧误解成整张发黑。</li>
    <li>白平衡：先看自动结果；同一场景中提高 WB 数值会更暖，但只用 WB 无法做出“暖高光 + 青绿阴影”。</li>
    <li>时机：日落前后、室内暖灯刚亮而环境仍有蓝色时最容易出现冷暖分离。</li>
  </ul>
</ParamCard>

后期起点：

| 调整 | 起步范围 | 目的与停止信号 |
| --- | --- | --- |
| 色温 | `+5～+15` | 建立琥珀感；白墙明显橙黄就停 |
| 对比 | `+5～+15` | 让旧相册感更扎实；脸部阴影堵住就停 |
| 高光 | `-5～-20` | 保暖灯形状，不把所有亮部压平 |
| 黑位 / 褪色 | 抬 `3～8` | 轻微旧印相感；黑衣发灰就停 |
| 饱和度 | `-5～+5` | 保留红棕色，不追求全面鲜艳 |
| 阴影色 | 少量青 / 绿 | 与暖高光分开；肤色发绿就减弱 |
| 颗粒 | `12～25` | 有相册触感，但不盖住眼睛和文字 |

富士官方对 `CLASSIC Neg.` 的说明强调消费级负片记忆中青绿色阴影、偏品红高光和较硬反差；`NOSTALGIC Neg.` 则强调琥珀色带来的怀旧感。这里只把这些关系当作学习参考，不复制相机内置配方：[CLASSIC Neg.](https://www.fujifilm-x.com/en-gb/products/film-simulation/classic-neg/) · [NOSTALGIC Neg.](https://www.fujifilm-x.com/global/products/film-simulation/nostalgic-neg/)

## 路线三：雨夜青绿负片

这一条和你喜欢的 post-punk、dreampop、shoegaze 最容易连接。它不是把黑夜全部染青，而是：**冷暗环境里留下暖灯、湿地反光、颗粒与有限的光晕。**

适合拍：

- 雨后街道、便利店、自动售货机
- 公交站、地铁口、玻璃橱窗
- 路灯下经过的人、撑伞背影
- 冷色环境和暖色窗口同时出现的现场

<ParamCard title="雨夜青绿拍摄起点" intro="夜色要保留，灯也要有形状。先稳住，再决定是否拖影。">
  <ul>
    <li>焦段：`1x` 最稳；`2x` 适合隔街压缩灯光，超广角只在需要夸张空间时用。</li>
    <li>定住人物：`1/60s-1/125s`，`ISO 400-1600`。</li>
    <li>轻微拖影：`1/15s-1/8s`，让墙、店面或路缘保持稳定锚点。</li>
    <li>曝光：自动模式先试 `-0.3EV/-0.7EV`；灯牌有形、暗部仍有环境信息即可。</li>
    <li>白平衡：混合灯下从 `3500K-4500K` 试起；在同一现场降低数值会更冷，提高会更暖。</li>
    <li>测光：点人物或中间调后再调曝光；点最亮灯通常会保护高光并压暗环境。</li>
  </ul>
</ParamCard>

后期起点：

| 调整 | 起步范围 | 目的与停止信号 |
| --- | --- | --- |
| 曝光 | `-5～0` | 保留夜感；人物完全不可读就回升 |
| 对比 | `+10～+25` | 拉开灯与夜；湿路细节消失就停 |
| 高光 | `-10～-30` | 灯有形状；想要局部晕染可少压一点 |
| 色温 | `-5～-15` | 环境略冷；暖灯也变惨白就停 |
| 阴影色 | 少量青绿 | 给夜色方向；灰墙明显荧光绿就停 |
| 饱和度 | `-5～-15` | 收住霓虹；关键暖灯仍应有颜色 |
| 颗粒 | `18～35` | 夜色更粗糙；小图满是噪点就减弱 |
| 光晕 | 只加在强灯周围 | 全图发雾或文字融化就过量 |

## 小米 15 Ultra 的稳定工作流

1. 先决定走三条路线中的哪一条，只写 3 个关键词。
2. 普通模式拍一张，检查主体、高光和现场颜色。
3. 只改曝光补偿再拍一张，不要同时乱改所有参数。
4. 需要固定快门、ISO 或白平衡时再进专业模式。
5. 重要画面可以保留 RAW/DNG，但普通成片也要留作颜色参考。
6. 后期先做裁切和曝光，再做颜色分离，最后才加颗粒、柔化和光晕。
7. 同一组照片套用同一方向后逐张微调，不要每张重新发明风格。

## 不是“日本场景”才可以拍

日式胶片气质来自观看和颜色组织，不来自地理标签。你完全可以拍：

- 楼下小店和居民区
- 公交站、学校外墙、旧小区
- 家里的餐桌、窗帘和日常用品
- 雨后路面、便利店和夜班路口

不要为了“日系”强行寻找樱花、和服、日文招牌或日本街道。题材越是你自己的日常，最后越可能从模仿变成个人风格。

## 专题作业怎么拍

<PracticeCard title="同一种日常，三条胶片路线" intro="不要找三个毫无关系的题材。尽量围绕同一条街、同一个人或同一个生活区域完成。">
  <ol>
    <li>选一条路线拍 6 张，并写下你的 3 个关键词。</li>
    <li>再选同一场景拍“正常版本 + 风格版本”，至少完成 3 组对照。</li>
    <li>有余力时把三条路线各拍 3 张，比较哪一条最接近你的观看习惯。</li>
    <li>提交时同时发一张原始成片和最终版本，说明你保留了什么、牺牲了什么。</li>
  </ol>
</PracticeCard>

## 交作业前自检

- 不看标题时，三条路线能不能被颜色和光线区分
- 白色、肤色和灰墙有没有被全局偏色污染
- 高光有没有柔和，但仍保留重要形状
- 阴影偏青绿是在制造层次，还是单纯发脏
- 颗粒关闭以后，照片是否仍有主体、光线和构图
- 同组照片是否像同一卷“想象中的胶片”，而不是六个滤镜

## 我会怎么点评

我会优先看：

1. 你选择的路线是否清楚
2. 场景和光线是否适合这条路线
3. 拍摄曝光是否给后期留下空间
4. 高光、阴影、肤色和主色有没有各自秩序
5. 颗粒、褪色和光晕是否克制
6. 风格版本是否比正常版本更接近你的表达，而不只是变化更大

## 这一专题最重要的一句话

**日式胶片不是一个预设，而是你对日常光线、颜色和记忆感做出的一组克制选择。**
